# 视频上传适配器

以下是编写时（2026-10）常见的选项，仅作发现参考，不是硬依赖。使用前核对项目的当前状态、许可证和平台条款。

## YouTube Data API（官方）

- 方式：`videos.insert` 上传视频并设置标题、描述、标签、分类、公开范围和定时时间；`captions.insert` 上传字幕；`thumbnails.set` 设置缩略图。
- 授权：用户本人在 Google Cloud 创建项目并完成 OAuth 授权；凭据文件和令牌保存在用户本机，不进任务卡和仓库。
- 限制：未通过审核的 API 项目上传的视频会被锁定为私密，正好对应 L2“私密上传，用户检查后在 Studio 公开”。每日配额有限，上传会消耗较多配额。
- 适合：YouTube 的 L2 和 L3。

## 填表类浏览器扩展（如 MultiPost）

- 方式：在用户已登录的浏览器中，打开各平台发布页并自动填入视频、标题、描述和话题，由用户检查后亲自点发布。
- 覆盖：常见版本支持抖音、视频号、小红书、YouTube、B 站等多个平台的视频发布页。
- 边界：不需要 API Key；账号登录态留在用户浏览器内。智能体通常无法直接操作扩展，由用户触发。
- 适合：L1。

## 浏览器自动化上传工具（如 social-auto-upload）

- 方式：基于 Playwright 等浏览器自动化，用户扫码登录一次后由工具在本机保存登录态，之后用命令行上传视频，支持定时发布。
- 覆盖：常见版本支持抖音、视频号、小红书、快手、B 站、TikTok、YouTube 等。
- 风险：非官方自动化，平台改版会导致失效，也可能触发风控或违反平台条款。登录态文件属于敏感凭据，只留在工具自己的目录，不复制、不提交。
- 适合：用户明确接受风险后的 L2 或 L3；起号阶段建议少用。

## 已登录浏览器（智能体操作）

- 方式：智能体在用户已登录的浏览器中打开发布页、填写字段，停在“发布”按钮前，由用户点击。
- 边界：遇到登录、验证码、短信验证或风控提示立即停止；不代输密码；上传文件、勾选声明等动作在执行前向用户说明。
- 适合：L1。

## 选择建议

| 场景 | 建议 |
|---|---|
| 起号初期，每条都想亲自把关 | L0 手动发布包，或 L1 填表助手 |
| YouTube 稳定更新 | 官方 API 上传为私密（L2），检查后公开 |
| 节奏稳定、接受非官方工具风险 | 浏览器自动化工具定时发布（L3），逐条授权 |
