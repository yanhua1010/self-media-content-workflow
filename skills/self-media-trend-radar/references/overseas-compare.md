# 海外对照模式

对同一批话题，分别统计海外（X、YouTube、Reddit）和国内（小红书、抖音、B站）近期内容的互动热度，判断话题在两侧的冷热差：

- 海外热、国内冷：可以引入国内的选题
- 国内热、海外冷：可以带出海的选题或内容形式

该模式只回答「两边热度是否有差」，不替代研究流程中的结构拆解和原创判断。

## 前提

- 本机 Python 3.11 及以上，无第三方依赖。
- 一个 [AIsa](https://aisa.one) API key，放在环境变量 `AISA_API_KEY` 中。AIsa 通过 REST API 提供上述 6 个平台的公开数据，国内平台数据来自 TikHub。
- 环境里没有 key 时，不运行脚本，回到 SKILL.md 的常规研究流程，用公开搜索人工抽样。

API key 只从环境变量读取。不要把 key 写进命令行参数、话题文件、任务卡、日志或聊天记录。

## 运行

脚本位于本 Skill 的 `scripts/` 目录，在任务工作目录执行：

```bash
cp <skill-dir>/scripts/topics.example.toml topics.toml   # 编辑话题和关键词
python3 <skill-dir>/scripts/overseas_compare.py quote     # 免费估价，不执行
python3 <skill-dir>/scripts/overseas_compare.py run       # 实际调用
python3 <skill-dir>/scripts/overseas_compare.py replay overseas-compare/raw/<日期>   # 用已保存数据重出报告，不计费
```

`topics.toml` 中每个话题包含一组英文关键词（`en`，用于海外平台）和一组中文关键词（`zh`，用于国内平台）。工作目录没有 `topics.toml` 时使用自带示例。

输出写到 `overseas-compare/`：`raw/<日期>/` 保存原始响应，`reports/<日期>.md` 是报告。常用参数：`--budget 0.2` 设置本次费用上限，`--platforms x xiaohongshu` 只运行部分平台，`--out <目录>` 修改输出位置。

## 费用与授权

按 2026-11 实测单价，每个话题一组关键词约 $0.03：

| 平台 | 接口 | 单次 |
|---|---|---|
| 小红书 | 笔记搜索 | $0.01 |
| 抖音 | 视频搜索 | $0.01 |
| B站 | 综合搜索 | $0.001 |
| X | 高级搜索 | $0.003 |
| YouTube | 搜索（限本月上传） | $0.0029 |
| Reddit | 搜索 | $0.0019 |

执行 `run` 前先运行 `quote`，把调用次数和预估费用告诉用户，获得同意后再执行。每次运行有费用上限（默认 $0.5，可在 `topics.toml` 的 `budget_usd` 或 `--budget` 修改）；单次请求的价格上限随剩余预算收紧，超出时网关直接拒绝，不会超支。

## 评分口径

1. 单条内容的互动量按平台加权求和，再取 `log10`。差 1 分约等于互动量相差 10 倍。
2. 只统计最近 `window_days` 天（默认 14）发布的内容，取互动最高的 5 条的平均值作为该侧热度。
3. 热度差 = 海外热度 − 国内热度。≥ 1 判为「海外热、国内冷」，≤ −1 判为「国内热、海外冷」，其余为「两边热度接近」。

| 平台 | 互动量 | 说明 |
|---|---|---|
| X | 点赞 + 2×转发 + 回复 + 浏览/100 | |
| YouTube | 播放/50 | 发布时间只有「5d ago」类相对时间，按近似值处理 |
| Reddit | 得分 + 2×评论 | |
| 小红书 | 点赞 + 收藏 + 2×分享 + 评论 | 按热度排序搜索 |
| 抖音 | 点赞 + 收藏 + 2×分享 + 评论 | 搜索接口返回的播放量为 0，不计入 |
| B站 | 播放/50 | 搜索接口不返回点赞 |

## 解读与限制

- 宽泛的大词（如产品名）两边通常都有覆盖，热度差小。差值更可能出现在具体功能、新工具和新术语上，关键词应尽量具体。
- 热度差只说明公开互动的差异，不代表需求、转化或商业价值。投流、账号体量和单条爆款都会影响结果，报告中的前 5 条内容需要人工复核。
- 当前版本靠关键词对匹配话题，中英文同义表达需要在 `topics.toml` 中手动补全。
- 单次运行无法判断国内比海外晚了几天，需要积累多日数据后再比较。

## 交给后续流程

把报告中热度差明显的话题，按 SKILL.md 第 3 至 5 步继续拆解结构、判断机会、转成原创选题。报告里的帖子只作为样本和来源链接，不复制原文。
