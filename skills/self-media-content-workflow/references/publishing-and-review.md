# 发布与复盘

## 两层授权

外部写操作必须依次获得：

1. 终稿确认。
2. 创建草稿或进入发布阶段的明确授权。

“看起来可以”“先放着”“晚点看看”不视为授权。不要直接群发。

## 创建草稿

公众号优先调用 `self-media-wechat-publisher`：它负责排版、图片上传和草稿写入，并遵守本文件的两层授权与核对要求。其他平台存在已认证连接器、官方 API 或已登录浏览器时：

1. 写入确认过的标题、摘要、作者、正文、封面和图片。
2. 保存为草稿。
3. 重新打开草稿。
4. 核对标题、摘要、正文前两段、封面、图片数量和外链。
5. 把草稿时间和核对结果写回任务卡。

登录、验证码、管理员确认或风控出现时停止并让用户接管。没有草稿能力时交付手动发布包。

## 视频发布

视频成片调用 `self-media-video-publisher`。它先交付逐平台发布包，再按用户逐平台授权的级别执行：填表助手由用户亲自点发布；私密上传或草稿由用户在后台检查后公开；定时发布只在用户给出平台、视频和时间后执行。登录、验证码、短信验证或风控出现时停止并让用户接管。

## 手动发布包

X、小红书、视频号、抖音和其他平台默认由用户手动发布。只交付与所选平台有关的：

- 最终文案。
- 封面和素材顺序。
- 标签、话题、首评、合集或 BGM。
- 商业合作声明。
- 发布后需要回填的数据。

用户报告发布成功后再记录链接和时间，不假设已经发布。

## 发布后数据

在用户选择的观察窗口记录曝光、阅读或播放、完播、点赞、评论、收藏、分享、新关注、转化和制作时间。平台不提供的字段留空。

复盘调用 `self-media-content-analytics`。只比较同平台、同内容类型和相近时间窗口。样本不足时不调整长期策略。
